Testing Gateways

When you want to test a Consumer-Provider pair that has a gateway as an intermediary, you must instead write the tests to target the gateway. Thus the direct link gets broken and instead you end up with two pairs, where the gateway is the Provider of the original Consumer and the Consumer of the original Provider. When the gateway receives a contract for verification, it will automatically transform it into a contract that it can pass on to the original Provider. From the point of view of the Consumer, the process is therefore almost exactly the same as it would have been without the gateway.
