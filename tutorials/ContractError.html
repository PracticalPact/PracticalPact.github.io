Contract error

Pact lets you control how much output you see during verification. The options are Error, Warn, Info, Debug, Trace, and None. The default is Warn, and this guide shows errors at that level.

Pending Pacts

When a consumer publishes a new pact that the provider has never verified before, it starts in a pending state. This means that even if verification fails, it will not block deployment. Once the provider has verified it successfully for the first time, it leaves pending state and future failures will block the build as normal.
