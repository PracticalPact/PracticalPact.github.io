In the scenario of Casino Frontend → Gateway → FavoriteApi:

The gateway creates two seperate contracts. One called Casino->Gateway and another called Gateway->Favorite.

Casino as a consumer relates to provider called GW->Favorite.
Casino->Gateway as a consumer relates to Favorite as a provider
The pact matrix has two pairs. Casino - GW->Favorite (pair 1) and Casino->GW - Favorite (pair 2).

When applying can-i-deploy, we want that in the pair 1, both consumer and provider only has one version each. For pair 2, we need to have note two versions: one for casino and one for gateway.
