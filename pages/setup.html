Setting up a Pact Project

Goal

This page explains how to prepare a project for Consumer-Driven Contract Testing.

Prerequisites

  • Either a consumer service or a provider service
  • Access to the source code repository
  • A test framework for the project language

Steps

  1. Install the relevant Pact library for the project language.
    Example for .NET 
    
                            #Find in Nuget package manager
                            PackageReference Include="PactNet" Version="5.0.1"
                            PackageReference Include="PactNet.Output.Xunit" Version="1.0.0"
    Example for JavaScript 
    
                            #Install via npm
                            npm install @pact-foundation/pact
                            npm install @pact-foundation/pact-cli@^18.0.0
  2. Create a contract test project or test folder.
  3. Configure the consumer name and provider name.
  4. Write the first consumer test.
  5. Run the test and generate a contract file.
  6. Publish the contract to the Pact Broker.
  7. Set up provider verification against the published contract.

Output

A project that can generate and publish Pact contracts.
