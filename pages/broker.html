Pact Broker

Purpose

The Pact Broker stores contracts, service versions, verification results, and dependency information.

Main functions

  • Stores contracts from consumers
  • Allows providers to retrieve contracts
  • Stores provider verification results
  • Shows which services depend on each other
  • Supports deployment decisions based on compatibility

Typical workflow

  1. Consumer publishes a contract.
  2. Provider retrieves the contract.
  3. Provider verifies the contract.
  4. Broker stores the verification result.
  5. Teams use the broker to check service compatibility.

Output

A central overview of contracts and compatibility between services.
