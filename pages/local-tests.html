Running Contract Tests Locally

Goal

Developers should be able to run contract tests before committing code.

Consumer tests

  1. Start the consumer test suite.
  2. Let Pact start the mock provider.
  3. Run the consumer interaction tests.
  4. Check that a contract file is generated.

Provider tests

  1. Start the provider service locally.
  2. Retrieve or load the relevant contract.
  3. Run provider verification.
  4. Review any failures.

Output

Local feedback before contract changes are pushed to the shared broker.
