CI/CD Integration

Goal

Contract testing should run automatically as part of the development pipeline.

Consumer pipeline

  1. Run consumer tests.
  2. Generate contract files.
  3. Publish contracts to the Pact Broker.

Provider pipeline

  1. Retrieve relevant contracts from the Pact Broker.
  2. Run provider verification tests.
  3. Publish verification results to the Pact Broker.

Decision points

  • If verification passes, allow the pipeline to continue.
  • If verification fails, block deployment or notify the provider team.
  • If the failure is caused by missing test setup, update the provider test configuration.

Output

Automated compatibility checks in the CI/CD pipeline.
