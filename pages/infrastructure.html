Infrastructure Setup

Goal

This page describes the infrastructure needed to run and manage contract testing.

Required components

  • Pact Broker
  • Database for the Pact Broker
  • CI/CD pipeline
  • Repository access
  • Internal hosting environment, such as Docker or Kubernetes

Steps

  1. Deploy a Pact Broker.
  2. Connect the broker to a database.
  3. Configure access from consumer and provider repositories.
  4. Configure environment names, such as test and production.
  5. Verify that contracts can be published and retrieved.

Output

A working contract testing infrastructure that supports contract publication, verification, and visibility.
