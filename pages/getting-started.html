Getting started with Practical Pact

Implementing Consumer-Driven Contract Testing requires changes to your test projects, CI/CD pipelines, and the way Consumers and Providers coordinate changes. Practical Pact provides a set of tutorials that guide you through these steps.

We recommend adapting the tutorials into an organisation-specific implementation guide before assigning the work to individual teams. This guide can include examples that work with the organisation’s programming languages, CI/CD platform, Pact Broker, repository structure, security requirements, and infrastructure.

Teams can then use this guide as a shared reference when implementing CDCT. This helps ensure that they follow the same naming conventions, workflows, deployment checks, and technical setup.

How to get started

  1. Choose a service and identify whether it acts as a Consumer, a Provider, or both.
  2. Follow the relevant tutorial and implement the first contract test locally.
  3. Configure the Consumer and Provider names used in the contract.
  4. Publish the generated contract to a Pact Broker.
  5. Configure the Provider to verify the published contract.
  6. Add contract testing and deployment checks to the relevant CI/CD pipelines.
  7. Repeat the process for additional service interactions.
