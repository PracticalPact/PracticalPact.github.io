A Brief Introduction to Contracts

Builds on the concepts introduced in A Brief Introduction to CDCT.

Communication in CDCT is defined as the Consumer sending a request to the Provider, followed by the Provider sending a response to the Consumer. A Contract is essentially made up of a number of these exchanges, which we will call Scenarios. Each Scenario additionally has a description of what happens in the Scenario. A description is simply text without further meaning.
