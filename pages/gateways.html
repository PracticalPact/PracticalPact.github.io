Contract Testing with Gateways

Problem

Pact normally assumes a direct consumer-provider relationship. A gateway adds an extra layer between the consumer and provider.

Method

Treat the gateway as its own service and create separate contracts for each boundary.

Steps

  1. Create a contract between the frontend and the gateway.
  2. Create a contract between the gateway and the backend provider.
  3. Verify that the gateway satisfies the frontend contract.
  4. Verify that the backend satisfies the gateway contract.

Decision points

  • If the gateway transforms requests, test the transformed request separately.
  • If authentication is converted by the gateway, do not claim that Pact verifies the full authentication flow.
  • If the gateway only routes traffic without transformation, the contract may be simpler.

Output

Verified contracts across both frontend-gateway and gateway-provider boundaries.
